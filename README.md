# Secure-boot-an515-57-acer
РЕШЕНИЕ ПРОБЛЕМЫ SECURE BOOT НА ACER NITRO 5 AN515-57
(подтверждённый случай, сентябрь 2026)

Проблема: в BIOS Secure Boot включён (Enabled), но режим залип в Custom. Windows и FACEIT видят Secure Boot как выключенный. Ошибка Firmware_MissingKEKInPackage — отсутствует ключ KEK 2023. Стандартные методы (сброс, перепрошивка, извлечение батарейки CMOS) не помогали.

Что сработало:
1. Дождаться обновления Windows. В моём случае пришло накопительное обновление KB5129195 (от 14.09.2026). После его установки и перезагрузки:
2. Зайти в BIOS (F2).
3. Вкладка Security:
   - Выбрать "Restore Secure Boot to Factory Default" → Enter → подтвердить.
   - Затем выбрать "Erase all Secure Boot Setting" → Enter → подтвердить.
4. Перейти во вкладку Boot:
   - Найти "Secure Boot".
   - Переключить с Enabled на Disabled, затем сразу обратно с Disabled на Enabled.
5. Нажать F10, сохранить и выйти.
6. После загрузки Windows проверить: Win+R → msinfo32 → строка "Состояние безопасной загрузки" должна быть "Вкл."

Важно: метод сработал именно после установки обновления Windows, которое доставило недостающие сертификаты. Если не помогает — проверьте, что все обновления Windows установлены, и повторите шаги.

Ноутбук: Acer Nitro 5 AN515-57, BIOS InsydeH20 V1.22.
Автор решения: пользователь, пожелавший остаться анонимным (делится опытом для помощи другим).
